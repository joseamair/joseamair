### 👨‍💻 About Me

I am a software engineer focused on building **autonomous multi-agent developer workflows**, **high-throughput asynchronous backends**, and **intelligent telemetry systems**. I enjoy working at the intersection of agentic LLM runtimes, systems performance, and real-time distributed applications.

- 🔭 **What I'm building:** Autonomous CLI orchestrators and rolling quota managers that coordinate multiple AI coding agents across multiplexed terminals and isolated worktrees.
- 🚴 **Sports Science & Telemetry:** Architecting AI endurance platforms that ingest biometric data (Garmin, Strava, Intervals.icu) to dynamically plan training and fueling.
- ⚡ **Engineering Principles:** Clean separation of concerns, deterministic testing, zero-overhead asynchronous I/O, and developer-first CLI ergonomics.
- 🤖 **Explorations:** ROS 2 & Gazebo physical robotics simulation, Whisper audio pipelines, and high-concurrency multiprocessing benchmarks.
- 💬 **Ask me about:** Python internals, FastAPI architecture, agent execution loops, WebSockets, and performance profiling.
